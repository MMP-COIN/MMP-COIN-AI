# MMP COIN AI

ترمینال هوشمند پایش و تحلیل بازار رمزارزها

## مخزن اصلی توسعه

این مخزن، منبع اصلی کد برنامه، رابط کاربری، منطق تحلیل و ساخت نسخه اندروید است.

- وب‌سایت اصلی: https://mmp-coin.github.io/
- مخزن اصلی برنامه: https://github.com/MMP-COIN/MMP-COIN-AI
- انتشار APK: https://github.com/MMP-COIN/MMP-COIN-AI/releases/latest
- وضعیت ساخت و انتشار: بخش **Actions** همین مخزن

## موتور هوشمند کوانتومی

- هسته مشترک امتیازدهی تطبیقی QIE-5.0.0 و نرمال‌سازی یونیورس: `cloudflare-worker/quantum-core.js`.
- تصمیم نهایی Hunter از لایه واحد `cloudflare-worker/decision-engine.js` عبور می‌کند؛ گیت fail-closed کیفیت شواهد، تازگی داده، جریان معاملات اجراشده، تأیید چندصرافی، عمق دفتر سفارش، اعتماد و مدل ریسک را بررسی می‌کند. خروجی این لایه LONG/SHORT یا WAIT است و هیچ داده مفقودی را حدس نمی‌زند.
- QIE-5.0.0 از وزن‌دهی تطبیقی متناسب با رژیم بازار، پوشش شواهد، کیفیت داده و جریمه کهنگی/بیش‌کشیدگی استفاده می‌کند.
- لایه مدل‌های تخصصی، خروجی موتورهای مومنتوم، جریان سفارش، ساختار، چندتایم‌فریمی، رژیم و نقدینگی را با وزن شواهد ترکیب می‌کند؛ GPT-OSS 120B لایه استدلال زبانی است، نه جایگزین محاسبات عددی.
- نرمال‌سازی کندل، حذف داده تکراری و هم‌ترازی کندل بسته‌شده چندصرافی در ماژول مشترک `cloudflare-worker/market-data-core.js` انجام می‌شود.
- Hunter و Radar دفتر یادگیری جداگانه اما هم‌ساختار دارند؛ بازده ۵/۱۵/۶۰ دقیقه ثبت می‌شود. کالیبراسیون اعتماد فقط پس از ۳۰ نمونه بالغ ۵ دقیقه‌ای و حداکثر ±۵ واحد فعال می‌شود و امتیاز/گیت سیگنال را دست‌کاری نمی‌کند.
- Worker اصلی و رادار مستقل از همین هسته استفاده می‌کنند.
- یونیورس Spot و Futures بدون سقف ثابت ۱۰۰ نماد ساخته می‌شود؛ اسکن چرخشی برای کنترل نرخ درخواست و حفظ پایداری ادامه دارد.

## ساخت و انتشار

- منبع مرجع رابط کاربری اپ و وب در `www/index.html` نگهداری می‌شود؛ نسخه سایت ریشه در مخزن `MMP-COIN.github.io` به‌صورت خودکار از این فایل همگام می‌شود.
- تنظیمات برنامه اندروید در `capacitor.config.json` قرار دارد.
- آیکون‌ها و فایل‌های هویت بصری در `assets/` نگهداری می‌شوند.
- ساخت APK از طریق GitHub Actions انجام می‌شود.
- نسخه قابل بروزرسانی باید با کلید امضای ثابت پروژه ساخته شود؛ کلید و رمزهای آن فقط در GitHub Secrets نگهداری می‌شوند و نباید در کد یا فایل‌های عمومی قرار بگیرند.

## معماری انتشار وب

`www/index.html` و `assets/` در این مخزن منبع مرجع هستند. مخزن `MMP-COIN.github.io` هر ۱۵ دقیقه و هنگام تغییرات خودش، نسخه منتخب را از این مخزن همگام و منتشر می‌کند.

دامنه ریشه سازمان یعنی `mmp-coin.github.io` به مخزن جداگانه `MMP-COIN.github.io` متصل است. تغییرات محصول باید ابتدا در همین مخزن اصلی توسعه داده شوند و نسخه سایت ریشه نیز جداگانه هماهنگ شود.

## نکته ایمنی

تحلیل‌ها و قیمت‌ها برای پشتیبانی از تصمیم‌گیری هستند و تضمین سود یا توصیه قطعی سرمایه‌گذاری محسوب نمی‌شوند.
